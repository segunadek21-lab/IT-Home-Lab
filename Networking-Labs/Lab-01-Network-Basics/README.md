# Lab 1 – Network Basics

## Objective
Learn how to identify network settings and my computer's IP configuration.

## Tools
- Terminal
- ping
- ifconfig/ipconfig
- nslookup
- traceroute

## Commands Used
### Windows
ping google.com

ipconfig /all

tracert google.com

### MacOS

ping google.com

ifconfig google.com

traceroute google.com
