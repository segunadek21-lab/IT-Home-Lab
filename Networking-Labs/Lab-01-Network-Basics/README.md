# Lab 1 – Network Basics

## Objective
Learn how to identify network settings and my computer's IP configuration.

## Tools

- Terminal
- ifconfig/ipconfig
- traceroute

## Commands Used
### Windows
ipconfig /all

ping google.com

tracert google.com

### MacOS
ifconfig

ping google.com

traceroute google.com
