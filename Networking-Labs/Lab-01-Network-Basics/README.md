# Lab 1 – Network Basics

## Objective
Learn how to identify network settings and my computer's IP configuration.

## Tools

- Terminal
- ifconfig/ipconfig
- traceroute

## Commands Used
### Windows
ipconfig /all

ping google.com

tracert google.com

### MacOS
ifconfig

ping google.com

traceroute google.com

## What I Learned

These commands are essentials in troubleshooting network issues in workstation. IT Technicians should be able to navigate these commands and understand what the results produced.

## Real-World Use

IT support technicians use these commands to diagnose internet, DNS, and connectivity problems.
